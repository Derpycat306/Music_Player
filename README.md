# Music Player

A desktop music player for organizing and playing a local music library, built with **React, TypeScript, JavaScript, CSS, HTML, and Electron**. The application provides a modern interface for browsing artists, albums, playlists, and individual songs within the users own filesystem.

## Features

* 🎵 **Local music library** — Select a local music folder and automatically discover supported audio files.
* 📀 **Artist and album browsing** — Organize music using metadata embedded in audio files.
* 🖼️ **Album artwork** — Automatically retrieve album artwork from local album folders.
* ▶️ **Playback controls** — Play, pause, seek, skip, and control volume.
* ❤️ **Favorites** — Save favorite songs for quick access.
* 📋 **Playlists** — Create and manage custom playlists.
* 🔍 **Library navigation** — Browse music by artist, album, and song.
* 💾 **Persistent settings** — Store application settings, favorites, and other user data between sessions.
* 🔄 **Automatic library updates** — Detect changes to the selected music directory.
* ⬆️ **Automatic updates** — Check for and install new application releases.

# Setup

For best usage, the local music files should be organized in the following format to avoid metadata inconsistencies:
Folder/
  Artist/
    Album/
      songs or album cover
